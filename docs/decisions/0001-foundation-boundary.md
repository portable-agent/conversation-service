# ADR-0001: Каркас до правил хранения

- Status: accepted
- Date: 2026-09-14

## Решение

Первый пакет создаёт сборку, generated API, security и проверки. Таблица сообщения и HTTP endpoint не
добавляются до решения о хранении исходного текста и сроке удаления.

## Причина

Структуру сервиса можно проверить без выдуманного поведения. Privacy-решение влияет на схему базы,
логи и права пользователя, поэтому оно не должно появляться случайно внутри технического PR.
