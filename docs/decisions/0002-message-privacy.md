# ADR-0002: Privacy-first хранение сообщения

- Status: accepted
- Date: 2026-09-14

## Решение

Исходный текст нужен только пока диалог открыт. При явном закрытии или после 24 часов сервис заменяет
его на `NULL` и отмечает время удаления. Текст нельзя писать в логи.

Ключ запроса и технические поля сохраняются после удаления текста, чтобы повтор доставки не создал
новое действие. Срок хранения этих полей будет определён отдельно до production.

## Причина

Канал может прислать сообщение повторно, поэтому идемпотентность должна переживать закрытие диалога.
При этом бессрочно хранить фразу пользователя для этой защиты не требуется.
