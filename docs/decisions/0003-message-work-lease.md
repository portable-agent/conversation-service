# ADR-0003: Короткий lease обработки сообщения

- Status: accepted
- Date: 2026-09-14

## Решение

Сообщение проходит состояния `NEW`, `PROCESSING`, `READY`, `FAILED` и `ERASED`. Перед внешней работой
worker делает атомарный SQL claim. Сетевой вызов выполняется без открытой транзакции базы, после чего
результат сохраняется отдельной транзакцией.

Lease `PROCESSING` действует две минуты и настраивается через environment. После срока другой worker
может повторить попытку. Каждый claim получает новый случайный token. Сохранить результат или ошибку
может только worker с текущим token, поэтому запоздавшая попытка не перезапишет новую. В базе хранится
только безопасный код ошибки, а не текст exception.

## Причина

Транзакция PostgreSQL не может атомарно охватить HTTP-вызов другого сервиса. Lease защищает от обычной
параллельной доставки и позволяет восстановиться после остановки процесса без долгой блокировки базы.
