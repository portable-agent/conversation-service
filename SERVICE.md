# Паспорт Conversation Service

## Ответственность

- состояние диалога;
- идемпотентность входящего сообщения;
- вызов Agent Runtime;
- создание сохранённого действия через Action Service;
- ответ с текстом или карточкой подтверждения.

## Не входит в ответственность

- протокол Telegram, VK или Web;
- разбор текста моделью;
- выполнение action и проверка payload hash;
- вызов MCP;
- отображение карточки.

## Текущее состояние

Подготовлены generated API `2.3.0`, PostgreSQL-схема и jOOQ repositories. Повтор сообщения с тем же
`requestKey` не создаёт дубль. Исходный текст стирается при закрытии диалога и после 24 часов.
Атомарный lease не даёт двум worker одновременно обрабатывать сообщение; зависшая работа доступна для
повтора через две минуты.

HTTP endpoint и интеграции с Agent Runtime и Action Service ещё не реализованы.
